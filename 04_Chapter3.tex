\chapter{Results and Post-Processing}
\label{ch:results}

This chapter outlines the post-processing architecture developed to parse, visualize, and compare the quantitative outputs across the 24 DoE simulations. It describes the structure of the OpenFOAM function objects, the automated HTML/Plotly reporting dashboard, and the flow-response quantities relevant to eventual valve-design comparisons. %

\section{Structure of OpenFOAM Post-Processing Data}
\label{sec:postprocessing_structure}
During the execution of \texttt{simpleFoam}, runtime function objects defined in \texttt{system/controlDict} continuously evaluate surface integrals, wall shear metrics, and aerodynamic forces, writing the output into the \texttt{postProcessing/} directory starting from time folder \texttt{0/}. %
Each simulation generates five specific data streams: %

\begin{itemize}
    \item \textbf{Inlet Average Pressure (\texttt{inlet\_pressure\_avg/0/surfaceFieldValue.dat}):} Tracks the area-averaged kinematic pressure across the \texttt{inlet} patch over solver iterations. %
    \item \textbf{Outlet Average Pressure (\texttt{outlet\_pressure\_avg/0/surfaceFieldValue.dat}):} Tracks the area-averaged kinematic pressure across the \texttt{outlet} patch, enabling direct computation of the overall valve pressure drop $\Delta P = P_{\text{in}} - P_{\text{out}}$. %
    \item \textbf{Inlet Volume Flux (\texttt{inlet\_volume\_flux/0/surfaceFieldValue.dat}):} Computes the surface integral of the velocity vector across the inlet patch (\texttt{areaIntegrate(U)}). %
    Because the inlet velocity is prescribed as a fixed Dirichlet boundary condition in a steady-state incompressible solver, the axial volumetric flux is nominally imposed by the inlet velocity. The reference range for the current campaign is $Q\approx2.39\times10^{-4}$ to $7.17\times10^{-4}\,\mathrm{m^3\,s^{-1}}$ (Table~\ref{tab:flow_regimes}), with the CFD-integrated value depending on the discretized inlet area. Actual inlet and outlet fluxes must be checked for conservation. %
    \item \textbf{Dimensionless Wall Distance (\texttt{yPlus1/0/yPlus.dat}):} Records the minimum, maximum, and area-averaged $y^+$ values across all solid wall patches (\texttt{wall1}, \texttt{wall2}, \texttt{wallObt}) to verify boundary layer resolution for the $k-\omega$ SST turbulence model. %
    \item \textbf{Obturator Forces (\texttt{forceCoeffs\_Obt/0/forces.dat}):} Logs the three-dimensional pressure force vector $\mathbf{F}_p = (F_{px}, F_{py}, F_{pz})$ and viscous force vector $\mathbf{F}_v = (F_{vx}, F_{vy}, F_{vz})$ acting on \texttt{wallObt}. %
    The total force component along the positive $x$ axis is given by $F_{x,\text{tot}} = F_{px} + F_{vx}$. %
\end{itemize}

\section{Automated Plotly Reporting and Master Dashboard}
\label{sec:plotly_dashboard}
To inspect convergence and compare physical quantities across all 24 simulations without manually opening 120 raw \texttt{.dat} text files, a batch post-processing script (\texttt{generate\_reports.py}, Appendix \ref{sec:app_plotly_script}) was built using the Python \texttt{Plotly} library \cite{plotly_docs}. %

The script employs custom text parsers and regular expressions (\texttt{re}) to extract time series and nested vector tuples from the OpenFOAM \texttt{.dat} files. %
For every simulation directory (\texttt{Sim\_*}), the script generates a standalone $2 \times 2$ responsive CSS grid dashboard (\texttt{CFD\_Report\_<CaseName>.html}) featuring four interactive charts: (1) Inlet vs. Outlet Pressure, (2) Inlet Volume Flux, (3) Patch-grouped Average $y^+$ Development, and (4) Total Forces ($F_x, F_y, F_z$) on the obturator. %

Furthermore, to provide a unified entry point for the entire DoE, the script automatically compiles a top-level \texttt{Master\_Dashboard.html} file. This master interface features a navigation sidebar listing all 24 simulation cases alongside an embedded HTML \texttt{<iframe>} container; clicking any simulation button triggers a JavaScript callback that dynamically loads the corresponding interactive Plotly report into the main viewport.

\section{Mesh Verification and Fluid Dynamic Trends}
\label{sec:fluid_trends}

The quantitative comparison of the \texttt{SIM\_DoE\_2210} cases is pending acceptance of the CFD solutions. The current hydrogen campaign contains cases requiring numerical stabilization, and no response surface, scaling exponent or final geometry ranking is presented as verified at this stage.

Once the cases meet the criteria in Section~\ref{sec:numerical_verification}, the analysis will compare the axial force, inlet-to-outlet pressure drop, dimensionless coefficients and mass-conservation error across the selected factors. Main-effect and interaction plots will be used to distinguish changes due to the number and diameter of holes from those associated with inlet velocity and working fluid.

Before computing dimensional cross-fluid comparisons, the force output density setting (\texttt{rhoInf}) and the reference density must be reconciled as discussed in Chapter~\ref{ch:numerical_setup}. Mesh quality, near-wall $y^+$ statistics and the sensitivity of the principal responses to grid resolution should also be documented. Only verified cases will be used as input data for the engineering selection tool.
